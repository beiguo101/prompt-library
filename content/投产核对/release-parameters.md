# 核对投产参数清单

逐项对照确认基准与待投产清单，找出值不同、缺项和额外项。

[参考 · Yila 方法对照图](https://yila.ai/scientific-figure-prompts/method-comparison)

## Prompt

请核对以下两份参数清单，生成可逐项复查的差异表。

本次投产范围：[系统、环境、模块]
已确认基准及版本：[粘贴]
待投产清单及版本：[粘贴]

先说明本次用哪些字段唯一识别一项参数，例如“环境＋模块＋参数名”。
按两份清单中出现过的全部参数核对。对每项列出：识别字段｜基准原值｜待投产原值｜核对结果。

核对结果使用：一致、值不同、待投产清单缺项、待投产清单额外项、无法唯一匹配。
保留原始字符串。只有材料明确给出等价规则时才合并等价值，否则分别处理空值、缺失、0、false、大小写差异和前导零。
同一识别字段出现多个值时，列出各条原记录供人确认。

先展示需要复核的项，再汇总各类数量。最终投产决定留给负责人。
