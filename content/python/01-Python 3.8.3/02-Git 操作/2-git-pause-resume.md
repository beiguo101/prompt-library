# 临时收起改动，再恢复原任务

明确收起范围，并核对暂存和未跟踪文件。

## Prompt

### 第 1 轮 · 确认保存范围

输入 [仓库与任务名称]。记录当前分支、工作区、索引与未跟踪文件，明确哪些纳入临时保存、恢复时是否恢复索引。只设计预览及验收。

目标运行环境为 Python 3.8.3。优先用标准库，采用可公开的虚构样例。交付可运行的入口、示例和验证结果；如果未能用 3.8.3 验证，请注明实际版本。

### 第 2 轮 · 实现收起和恢复

确认规则与授权：[填写]。开发保存及恢复入口，记录可稳定识别的保存记录。恢复前展示目标和现状。若恢复产生冲突，保留保存记录并给出当前状态。

### 第 3 轮 · 验证回到原状态

在临时仓库核对暂存、未暂存和未跟踪文件的保存前后状态；另外验证目标被修改时的冲突。明确恢复成功后如何由用户决定清理保存记录。
