# 只暂存并提交我选定的文件

先核对索引，确保提交不会带入其他改动。

## Prompt

### 第 1 轮 · 定义提交边界

材料：[仓库、目标文件、提交说明]。先检查工作区和暂存区，核对同时有暂存与未暂存改动的文件。设计预览，说明预计提交的内容及如何保留已有暂存项，等待确认。

目标运行环境为 Python 3.8.3。优先用标准库，采用可公开的虚构样例。交付可运行的入口、示例和验证结果；如果未能用 3.8.3 验证，请注明实际版本。

### 第 2 轮 · 实现受控提交

授权的文件和内容边界：[填写]。实现预览与显式应用，逐个传递路径参数。应用前重验当前状态；如果无法满足“只提交选定内容并保留其他暂存”的契约，停下给出原因。

### 第 3 轮 · 验证实际提交

在临时仓库放入其他已暂存文件、同一文件的工作区变化和空格路径。核对新提交的实际差异、提交前后索引及未暂存内容。报告无差异或提交失败时的状态。
