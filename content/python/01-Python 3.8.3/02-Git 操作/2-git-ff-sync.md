# 同步本地分支，遇到分叉停下

仅在满足前提时快进，其他情况给出证据。

## Prompt

### 第 1 轮 · 检查同步条件

输入 [仓库、目标分支和上游引用]。检查本地状态、上游可用性、当前引用和独有提交。列明是否需要获准刷新上游，并让用户确认同步范围。

目标运行环境为 Python 3.8.3。优先用标准库，采用可公开的虚构样例。交付可运行的入口、示例和验证结果；如果未能用 3.8.3 验证，请注明实际版本。

### 第 2 轮 · 应用快进

确认信息：[粘贴]。实现预览和显式应用，应用前重新核实分支与工作区。只在当前分支确实可快进时更新；分叉或工作区存在会受影响的变更时停下。

### 第 3 轮 · 验证三种结果

用临时仓库验证已同步、可快进和分叉。检查最终提交位置、未提交内容和分叉报告，不访问真实远端。
