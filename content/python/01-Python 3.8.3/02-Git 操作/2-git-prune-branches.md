# 筛选并清理已合并的本地分支

先预览候选，再按确认清单安全删除。

## Prompt

### 第 1 轮 · 定清理规则

输入 [仓库、比较基准、保留名单]。定义已合并候选的判断依据，排除当前分支、其他工作树正在使用的分支以及明确保留分支。给出预览字段。

目标运行环境为 Python 3.8.3。优先用标准库，采用可公开的虚构样例。交付可运行的入口、示例和验证结果；如果未能用 3.8.3 验证，请注明实际版本。

### 第 2 轮 · 实现预览与应用

确认的基准和删除清单：[填写]。实现只读预览和显式删除，应用前重新校验每个候选；任何条件变化时单列跳过原因。

### 第 3 轮 · 复查删除影响

用临时仓库覆盖已合并、未合并、保留和其他工作树在用四类。输出实际删除、跳过及理由，确认保留引用和工作树仍可访问。
