# 限制超时，并只重试暂时失败

按失败类型决定是否重试并记录最终结果。

## Prompt

### 第 1 轮 · 定义失败策略

输入 [任务入口、超时时间、错误类型、最大尝试次数]。确认暂时失败、不可重试输入错误及取消后如何验证产物状态。列出控制总运行时间的方案。

目标运行环境为 Python 3.8.3。优先用标准库，采用可公开的虚构样例。交付可运行的入口、示例和验证结果；如果未能用 3.8.3 验证，请注明实际版本。

### 第 2 轮 · 实现超时和重试

确认策略：[填写]。实现逐次超时、有限重试与间隔，记录每次原因和最终结果。开始重试前确保前一次已停止或已按约定清理。

### 第 3 轮 · 模拟验证

用本地模拟任务覆盖首次超时后成功、输入错误、重试耗尽三种情况。核对尝试次数、最后状态和部分产物是否按规则处理。
