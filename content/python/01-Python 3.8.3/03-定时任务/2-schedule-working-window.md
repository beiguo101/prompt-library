# 按工作日和时间窗口执行任务

明确时区、节假日和允许执行的边界。

## Prompt

### 第 1 轮 · 确认日历规则

输入 [时区、运行窗口、工作日和节假日来源]。定义窗口端点、跨午夜的归属、特殊日期覆盖和日历缺失时的行为。给出可比较的日期样例，等待确认。

目标运行环境为 Python 3.8.3。优先用标准库，采用可公开的虚构样例。交付可运行的入口、示例和验证结果；如果未能用 3.8.3 验证，请注明实际版本。

### 第 2 轮 · 接入执行条件

确认规则与现有调度方式：[填写]。开发接收计划时刻的执行判断，明确触发、跳过和需人工核对，并记录原因。使用显式输入或兼容的时区方案。

### 第 3 轮 · 验收边界

用模拟时钟复核工作日、周末、特殊日期、恰好到端点和跨午夜场景。适用的时区另验夏令时重复或跳过时刻，记录预期和实际行为。
