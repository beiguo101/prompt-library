# 防止同一个任务重叠运行

把重叠触发变成可解释的跳过或排队。

## Prompt

### 第 1 轮 · 确定重叠策略

输入 [任务及部署方式]。确认锁的粒度、单机或多机边界，及上一轮仍运行时跳过还是排队。说明异常退出后如何检查能否恢复。

目标运行环境为 Python 3.8.3。优先用标准库，采用可公开的虚构样例。交付可运行的入口、示例和验证结果；如果未能用 3.8.3 验证，请注明实际版本。

### 第 2 轮 · 实现占用判定

授权范围和选择：[填写]。在目标环境采用兼容机制取得运行权，记录运行标识和冲突结果。完成或异常结束时按约定释放。

### 第 3 轮 · 验证并发与恢复

用本地两个同时触发的进程验证实际处理次数、跳过或排队记录。额外模拟持锁进程退出，检查超时或恢复分支有证据可查。
