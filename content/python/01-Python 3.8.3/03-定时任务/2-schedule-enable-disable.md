# 管理任务的启用、停用和运行状态

使用现有调度器，保证重复启用不会产生双任务。

## Prompt

### 第 1 轮 · 核实目标环境

输入 [操作系统、已有调度器、任务入口和权限]。先只读确认该任务的标识、当前状态和可用动作。提出预览、启用、停用、查看和手动执行的接口。

目标运行环境为 Python 3.8.3。优先用标准库，采用可公开的虚构样例。交付可运行的入口、示例和验证结果；如果未能用 3.8.3 验证，请注明实际版本。

### 第 2 轮 · 实现管理入口

确认使用的调度器和授权范围：[填写]。支持预览及获准操作，给每次变更前后状态。对同一任务重复启用应保持一份计划，停用只影响该任务的新触发。

### 第 3 轮 · 验收启停

在临时环境或调度器替身验证初次启用、再次启用、停用、已停用及读取状态失败。列出与目标机器实测之间仍有差异的部分。
