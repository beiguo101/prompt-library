# 按业务测试问题号更新台账

合并开发答复和业务复测，保留状态依据。

## Prompt

### 第 1 轮 · 确认状态口径

输入 [上次台账]、[新增反馈] 和 [状态字典]。明确问题号匹配、时间相同或未知时的处理及关单依据。给出开发已修复但复测失败的预期行，等待确认。

目标运行环境为 Python 3.8.3。优先用标准库，采用可公开的虚构样例。交付可运行的入口、示例和验证结果；如果未能用 3.8.3 验证，请注明实际版本。

### 第 2 轮 · 实现台账更新

已确认规则与列映射：[填写]。按完整问题号合并，输出新增、变化和待复测事项。保留反馈方和时间；无编号或冲突记录单列。

### 第 3 轮 · 对账验证

用重复反馈、孤立反馈、复测失败和业务关单四类样例核对。输出条数及错误定位，说明原台账与新台账差异。
