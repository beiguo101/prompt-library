# 把跨组依赖整理成协调请求和汇报摘要

用同一份事实材料生成组间和管理层草稿。

## Prompt

### 第 1 轮 · 确认输入

输入 [任务清单、沟通记录和汇报对象]。确认本组期望、外组承诺和未确认字段的区分方式，列出两种草稿各自需包含的信息。

目标运行环境为 Python 3.8.3。优先用标准库，采用可公开的虚构样例。交付可运行的入口、示例和验证结果；如果未能用 3.8.3 验证，请注明实际版本。

### 第 2 轮 · 实现模板化整理

已确认的字段规则与输出结构：[填写]。开发从结构化输入输出两种本地草稿的工具。区分原文、人工决定与程序生成的待确认标记；输出供人审阅。

### 第 3 轮 · 验证两种输出

以只有本组期望日期、外组尚未承诺的样例验收。检查协调稿能说明需要答复什么，管理摘要能准确表述影响，并能回查输入记录。
