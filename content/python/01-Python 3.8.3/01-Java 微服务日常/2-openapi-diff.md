# 比对两版接口契约

先确认比较口径，再生成可回查的差异清单。

## Prompt

### 第 1 轮 · 确认比较范围

输入 [旧、新 OpenAPI JSON]。先确认规范版本、比较的接口范围，以及路径、方法、必填字段、类型和响应状态码的口径。对未支持的引用或组合结构列出边界，并给出验收样例，等待确认。

目标运行环境为 Python 3.8.3。优先用标准库，采用可公开的虚构样例。交付可运行的入口、示例和验证结果；如果未能用 3.8.3 验证，请注明实际版本。

### 第 2 轮 · 实现对照

授权范围与口径：[填写]。开发只读工具，逐项输出新增、删除、变化及疑似兼容问题，附两边的 JSON 路径。按已确认范围解析，未知结构明确报告。

### 第 3 轮 · 复核结果

用同一接口的新增必填字段、类型调整、状态码变化和纯文档改动验收。逐条核对预期差异和实际差异，注明未经验证的结构。
