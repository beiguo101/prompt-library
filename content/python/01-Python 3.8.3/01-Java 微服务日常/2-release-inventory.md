## Prompt

### 第 1 轮 · 确认映射

材料：[发布项、产物清单、SQL 文件清单]。提议服务与产物命名、版本和脚本排序规则，区分显式规则及待确认规则。列出少包、多包、错误版本和重复序号的验收样例。

目标运行环境为 Python 3.8.3。优先用标准库，采用可公开的虚构样例。交付可运行的入口、示例和验证结果；如果未能用 3.8.3 验证，请注明实际版本。

### 第 2 轮 · 产生差异表

确认的映射和授权范围：[填写]。实现只读对照，附输入版本、原始文件名及对应关系。对于多个匹配，保留候选和证据。

### 第 3 轮 · 复核验收

用虚构投产包验证缺项、错版、重复序号和正常路径。注明脚本排序检查基于清单规则，报告每一项的源条目。
