# 日常提示词库

首页显示类别。进入类别后可以直接复制提示词，也可以在详情浮窗中阅读正文和来源。Markdown 驱动，静态页面，构建无需安装 npm 包。

## 本地预览

在本项目目录运行：

```sh
node build.mjs
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

打开 http://127.0.0.1:4173/ 。也可直接打开 dist/index.html。

## 新增或修改提示词

日常工作模板放在 `content/分类名/`。Codex 学习工程和 Python 小工具模板分别放在 `content/codex/01-组名/01-分类名/` 和 `content/python/01-组名/01-分类名/`。每条各用一个 Markdown 文件，文件名前缀 `1-`、`2-`、`3-` 分别对应基础单轮、进阶多轮、高阶综合运用。分类与计数在构建时生成。

```markdown
# 条目标题

用一句话说明适用场景。

[参考 · 原始条目名称](https://example.org/reference)

## Prompt

在这里写完整指令和 [输入占位符]。
```

原创条目可以省略来源链接。公开内容使用通用模板和可公开示例，实际工作材料在获准的内部模型中填写。

多轮模板从 `## Prompt` 下的 `### 第 1 轮 · 轮次用途` 开始，每轮用一个标题和一段可单独发送的提示词。查看详情后可以逐轮复制。「复制全套」复制 `## Prompt` 下的全部内容，方便查看或保存完整步骤。

## GitHub Pages

把这个目录作为独立 GitHub 仓库的根目录。仓库设置的 Pages 来源选择 GitHub Actions。内置工作流在 main 更新时运行，也可手动触发。站点使用相对资源路径，支持默认仓库子路径。
